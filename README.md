# QUO_TURF
Optimizador de Alcance y Frecuencia con desempate no alfabético
# 🎯 QUO_TURF App

Esta aplicación permite realizar un **Análisis TURF (Total Unduplicated Reach and Frequency)** de forma profesional e interactiva. 

### ✨ Características principales:
* **Escaneo Dinámico**: Detecta automáticamente estímulos y variables de filtro.
* **Relevancia**: Lógica avanzada de desempate basada en sinergia futura.
* **Reportes en Excel**: Genera cuadros de jerarquía y gráficos de cascada listos para usar.
